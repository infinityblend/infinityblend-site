# infinityblend.app

Public pages for the Infinity Blend iPhone app, served by GitHub Pages at https://infinityblend.app.

- `index.html`: home page (coming soon). Hidden from search engines for now (`robots.txt` and `noindex`).
- `support/`: support and FAQ. This is the App Store support URL.
- `legal/`: Privacy Policy, Terms of Use and Drink Responsibly. **Generated, do not edit here.**
  They come from the app's `InfinityBlend/Legal/LegalDocuments.swift`. Rebuild them from the app repository with
  `scripts/build-site-legal.sh`, then commit here.
- `assets/`: icon, background and the shared stylesheet (colours match the app).
- `CNAME`: the custom domain.
